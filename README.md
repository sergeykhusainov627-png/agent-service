# AgentService — служебная сборка, пульт агента и канал управления

Проект для агентной разработки: даёт возможность читать и править модули
репозитория и компилировать сборки **без управления мышью и клавиатурой**.

Расположение: `F:\Scheduler Tasks\AgentService`. Ваш рабочий проект
(`F:\Scheduler Tasks\Fore`, `DeployTool`, `MyCodeEditor1`) не изменяется.

## Состав

```
AgentService\
├── Fore\
│   ├── Agent\AgentServiceForm.fore   ← пульт агента (главный файл)
│   └── *.fore                         копии исходников проекта (17 файлов, контекст)
├── tools\
│   ├── agent-cli.js                   клиент канала: команды и чтение ответов
│   └── fore-lint-check.js             ваш линтер
├── docs\                              FORELANG.md, REFERENCE.md, справка forsight
│   └── forsite-online.zip             онлайн-справка (8,9 МБ в архиве 1,2 МБ)
├── inbox\                             сюда кладутся команды (cmd.txt)
├── outbox\                            сюда пишутся ответы (out.txt, done.txt)
└── backup\                            бэкапы модулей перед записью
```

## Как это работает

```
я (agent-cli.js)                        платформа (AGENTSERVICEForm)
      │                                          │
      ├─ пишу inbox\cmd.txt ────────────────────►│ таймер раз в секунду
      │                                          │ читает файл
      │                                          │ выполняет через API:
      │                                          │   IModule.Text, Save,
      │                                          │   BindToAssembly, CheckCompiled
      │◄──────────── пишу outbox\out.txt ────────┤ бэкап → запись → ответ
      │◄──────────── маркер outbox\done.txt ─────┤
```

Интерфейс пульта строится **кодом из описания** (фабрика экранов `UiFactory`,
как в `UiFactoryDemo`): спроектированных контролов в форме нет. Кнопки пульта
делают то же самое, что приходит из файла — можно работать и руками, и извне.

## Что нужно сделать один раз

1. **Создать служебную сборку** в репозитории, например `AGENT_SERVICE`
   («Служебная сборка агента»).

2. **Создать объект «Форма»** внутри неё с идентификатором **`AGENTSERVICE`**.
   Имя класса должно получиться `AGENTSERVICEForm` — оно уже такое в модуле
   (соглашение проекта: класс формы = `<Id>` + `Form`).

3. **Вставить в модуль формы** содержимое `Fore\Agent\AgentServiceForm.fore`.

4. **Привязать события формы:**
   - `OnCreate` → `AGENTSERVICEFormOnCreate`
   - `OnClose` → `AGENTSERVICEFormOnClose`

5. **Ссылки сборок формы:** `Forms`, `Ui`, `System`, `Collections`,
   `Metabase`, `Fore`, `Io` + сборка, где лежит `UiFactory.fore`.
   Если компилятор не найдёт `IModule`, `IAssembly` или `ITextReader` —
   добавьте нужную сборку и посмотрите подсказку в шапке `DEPLOYTOOL.fore`.

6. **Проверить путь обмена.** В начале модуля:

   ```
   AGS_ROOT = "F:\\Scheduler Tasks\\AgentService";
   ```

   Двойные обратные слэши обязательны: так экранируется слэш в строке Fore.

7. **Запустить форму (F5).** Экран соберётся сам: два поля (модуль и сборка),
   восемь кнопок, журнал, строка состояния. Нажать **«Запустить канал»** —
   начнётся опрос файла команд.

## Проверка связи

Из консоли в папке `F:\Scheduler Tasks\AgentService`:

```bash
node tools/agent-cli.js ping
```

Ожидаемый ответ:

```
  AGENT           AgentService
  STATUS          OK
  WHAT            PING
  MSG             канал работает
```

Если ответа нет за 30 секунд — раздел «Если не работает».

## Кнопки пульта

| Кнопка | Что делает |
|---|---|
| **Запустить канал** | включает таймер опроса `inbox\cmd.txt` |
| **Остановить** | выключает опрос |
| **Проверить связь** | выполняет `PING` |
| **Инфо о репозитории** | имя репозитория, корень, число объектов |
| **Список объектов** | объекты верхнего уровня: Id, имя, класс |
| **Прочитать модуль** | текст модуля из поля «Модуль» |
| **Скомпилировать** | компилирует сборку из поля «Сборка», показывает `CheckCompiled` |
| **Очистить журнал** | чистит Memo |

## Команды из консоли

| Команда | Что делает |
|---|---|
| `node tools/agent-cli.js ping` | проверка связи |
| `node tools/agent-cli.js info` | репозиторий и корень |
| `node tools/agent-cli.js list` | объекты верхнего уровня |
| `node tools/agent-cli.js read <ModuleId>` | прочитать текст модуля |
| `node tools/agent-cli.js compile <AssemblyId>` | скомпилировать, показать `CheckCompiled` |
| `node tools/agent-cli.js write <ModuleId> <файл.fore>` | записать модуль (с бэкапом) |
| `node tools/agent-cli.js lint <файл.fore>` | баланс конструкций без платформы |

Ключи: `--timeout=60` — ждать дольше; `--raw` — вывести ответ как есть.

## Формат команд (вручную, если нужно)

Файл `inbox\cmd.txt`, кодировка UTF-8:

```
OP=READ
MOD=TASK_PLANNER
```

```
OP=WRITE
MOD=TASK_PLANNER
TEXT
Sub Test;
Begin
	Debug.WriteLine("новая версия");
End Sub Test;
```

```
OP=COMPILE
ASM=AGENT_SERVICE
```

Ответ — `outbox\out.txt`: строки `KEY=VALUE`, текст модуля после строки `TEXT`,
маркер завершения — `outbox\done.txt`.

## Безопасность

- **Бэкап до записи**: `backup\<ModuleId>_<дата_время>.fore`. Не создался — запись отменена.
- **Файл команды удаляется до выполнения** — двойного срабатывания не будет.
- **Операций удаления объектов** в модуле нет вообще.
- **Формы через XML не правятся** (`IForm.Content` по справке ломает форму) —
  только `IModule.Text`.
- **Обработчик таймера защищён `Try`** — исключение не закроет форму.
- **Освобождение компонентов** в `OnClose` через `UiFree` — как требует фабрика.

## Если не работает

| Симптом | Причина и что делать |
|---|---|
| `Ответа нет за 30 с` | Канал не запущен: нажмите «Запустить канал» на пульте |
| То же | Путь `AGS_ROOT` не совпадает. Проверьте, появляется ли `outbox` |
| `STATUS=ERR, MSG=объект не найден` | Неверный идентификатор. Посмотрите кнопкой «Список объектов» |
| `MSG=объект не является модулем` | Взят объект другого класса (отчёт, справочник). Читаются только модули и формы |
| `MSG=BindToAssembly: ...` | Сборка не найдена или в ней ошибки. Текст исключения — единственная диагностика от API |
| `CHECK_COMPILED=False` | Правка сломала сборку: восстановите модуль из `backup\` |
| Компилятор не находит `IModule`/`ITextReader` | Не хватает ссылки на сборку: `Fore`, `Io` |
| Экран пустой | Не привязан `OnCreate` → `AGENTSERVICEFormOnCreate` |

  модуля — из `DEPLOYTOOL.fore:1175-1189`, компиляция — из
  `EditorSpike.fore:244,285`, запись UTF-8 — из `EditorSpike.fore:453`,
  проверка `Reader.Eof` — из `DEPLOYTOOL.fore:717`.

**Не проверено:**

- модуль **не компилировался** на платформе: запустить компилятор из командной
  строки она не умеет. Первый запуск может выявить опечатку или нехватку ссылки;
- `Directory.CreateDirectory` и `File.Delete` в вашем коде не встречались
  (там только `Directory.GetFiles`) — если компилятор их не найдёт, уберите
  `EnsureDirs` и создайте `inbox`, `outbox`, `backup` вручную.

При первом запуске пришлите текст ошибки компилятора — поправлю сразу.
