## 1. Комментарии

- Однострочные — `// ...`
- Многострочные — `{ ... }`
- XML-документирующие — `/// <summary>...</summary>` (любые теги). Читаются в коде через свойство
  `XMLDocumentation` интерфейсов `IForeClass`, `IForeProperty`, `IForeSub`.

```fore
// однострочный
{ многострочный
  комментарий }
/// <summary>Комментарий к процедуре Test</summary>
Sub Test;
Begin
End Sub Test;
```

## 2. Переменные

Объявляются в разделе `Var`: `Имя: Тип;`, однотипные — через запятую. Типом может быть класс,
интерфейс или перечисление. Переменная живёт в пределах своего блока.

```fore
Var
	a, b: Integer;
	Sum: Double;
	Mb: IMetabase;
```

## 3. Константы

Раздел `Const`; тип определяется автоматически по значению. Могут вычисляться из ранее
объявленных констант. Область видимости: глобальная, пространство имён, класс (с модификатором
доступа), процедура/функция/свойство. В классе `Const` пишется для **каждой** константы.

```fore
Const
	_globalVersion = 1.0;
	_globalName = "Program";

Namespace TestNamespace
	Const
		_FileName = "Output";
		_Path = "c:\\Work\\";
	Public Class Test: Object
		Public Const _clsConst1 = 1;
		Const _clsConst2 = "#FF0000";
	End Class Test;
End Namespace TestNamespace;
```

**Зарезервированные константы:** `True`, `False`, `Null`.
`Null` — пустая ссылка; допустима для системных/пользовательских **объектов**, **интерфейсов**,
`Variant`, `Array`. Присвоение `Null` переменной простого типа → исключительная ситуация.

## 4. Типы данных

Все типы — производные от объектного `Object`. **Наследование от базовых типов запрещено.**
Типы значений: `Boolean`, `Char`, `Currency`, `DateTime`, `Decimal`, `Double`, `Integer`,
`TimeSpan`, `Variant`, `String`, `Int64`, `Guid` (и `Object`).

| Тип | Назначение / диапазон | Операции |
|-----|------------------------|----------|
| `Boolean` | `True`/`False` | логические, отношения, унарный `Not` |
| `Char` | один символ Юникод (`'A'`, `#Code`, `Char.Chr`) | отношения, `+` (результат — `String`) |
| `Currency` | денежный, 64-бит, 4 знака после запятой | отношения, `*`, `+`, `-` |
| `DateTime` | 01.01.0100 … 31.12.9999 | отношения, `+` (→`DateTime`), `-` (→`TimeSpan`) |
| `Decimal` | 16 байт, 0…28 разрядов; суффикс `m`/`M` (`1.123m`) | отношения, `*`, `+`, `-`, `/` |
| `Double` | вещественное, 8 байт (15–16 цифр) | отношения, `*`, `+`, `-`, `/` |
| `Integer` | 32-бит целое, −2147483648…2147483647 | отношения, арифметика, логические (побитно); `/` даёт вещественное |
| `TimeSpan` | промежуток времени | через класс `TimeSpan` (см. `REFERENCE.md` §5.19/§5.30) |
| `String` | текст Юникод (строки в `"..."`); до 2 Гб | `+`, сравнения (по коду символов) |
| `Variant` | тип определяется в рантайме; значение по умолчанию `Null` | все операции |
| `Guid` | уникальный идентификатор | `Guid.Parse`/`TryParse`/`IsGuid` |

```fore
Sub SampleBoolean;
Var
	b: Boolean;
Begin
	b := True;
	b := 1 < 0;
	b := Boolean.Parse("TRUE");
	b := Not b;
End Sub SampleBoolean;
```

> Константы в двойных кавычках — `String` (`"текст"`), в апострофах — `Char` (`'A'`).
> `#0` трактуется как конец строки. Число с суффиксом `m`/`M` — `Decimal`; без суффикса — `Double`
> (присваивание `Double` в `Decimal` даёт ошибку «Тип Decimal и Double не совместимы» — нужен `As`).

### Variant и преобразования
Неявное преобразование из `Variant` возможно, если тип совместим, иначе — исключение. Явное —
оператором `As`; проверка возможности — оператором `Is`. `Variant` поддерживается в `If` и `?:`.

```fore
v := 21.9;
i := v As Integer;   // 22
d := v As Double;    // 21.9
s := v As String;    // "21.9"
b := v Is Integer;   // True
```

## 5. Классы и объекты

Класс описывает объект: поля/константы, конструкторы, свойства, методы, события. Класс наследуется
от `Object` или пользовательского класса. **По умолчанию класс — `Private`.** Класс может
реализовывать интерфейсы. Предварительных описаний нет: предок должен быть определён раньше
потомков.

```fore
Public Class TUserInfo: Object
	_FirstName, _LastName: String;

	Public Constructor Create(Name: String = "");
	Begin
		_FirstName := Name;
	End Constructor Create;

	Public Property FirstName: String
	Get
	Begin
		Return _FirstName
	End Get
	Set
	Begin
		_FirstName := Value
	End Set
	End Property FirstName;
End Class TUserInfo;
```

- **`Self`** — ссылка на текущий объект (только внутри методов класса).
- **`Shared`** — статические (классовые) поля/методы: одна копия на все экземпляры; в статических
  членах доступны только статические.
- **`Final`** — метод нельзя переопределить в потомках.
- **События** — только через делегаты (см. ниже).

## 6. Конструкторы и `New`

Конструктор инициализирует новый объект; `Inherited` вызывает конструктор базового класса.
Объект создаётся оператором `New`. Если собственных конструкторов нет — используется стандартный
`Create`; если в потомке не объявлено ни одного — наследуются конструкторы родителя.

```fore
Obj1 := New TestObject1.Create(100);
Obj2 := New TestObject2.Create(Obj1.A + 100);   // внутри: Inherited Create(100);
```

`New` **не требуется** для простых типов (`Boolean`, `Char`, `Currency`, `DateTime`, `Decimal`,
`Double`, `Integer`, `TimeSpan`, `Variant`, `String`) — их переменные хранят значение, а не ссылку.

## 7. Свойства (Property)

`Get` — чтение, `Set` — запись. Два синтаксиса:

- **новый** — тело `Get`/`Set` внутри `Property ... End Property` (в `Set` доступно `Value`);
- **старый** — `Property Item: Type Get Get_Item Set Set_Item;` (методы `Get_*/Set_*`).

Свойство может быть **по умолчанию** (`Default`) — обращение без имени (`Arr(0)`). Переопределение
в потомке — через `Inherited`:

```fore
Public Property Item(i: Integer): String
Get
Begin
	Return PropValue[i];
End Get
Set
Begin
	PropValue[i] := Value;
End Set
End Property Item; Default;
```

## 8. Интерфейсы

`Interface ... End Interface` — контракт (только объявления свойств/процедур/функций, без кода:
нет `End Sub`/`End Function`). Наследование — не более чем от одного интерфейса; **от системных
интерфейсов наследовать нельзя**. Класс реализует интерфейсы после `:` через запятую.

```fore
Interface IMyInterface
	Public Property Item(i: Integer): String Get Get_Item Set Set_Item; Default;
	Public Property Items: Array Of String
	Get
	End Property Items;
End Interface IMyInterface;

Class MyArray: Object, IMyInterface
	// ... реализация членов интерфейса ...
End Class MyArray;
```

## 9. Перечисления (Enum)

`Enum ... End Enum`; константы получают целочисленные значения (по умолчанию 0, 1, 2, …; можно
задавать явно). Значения уникальны и возрастают. Переменная перечислимого типа принимает только
его значения.

```fore
Enum MyEnum1
	MyValue1, MyValue2, MyValue3          // 0, 1, 2
End Enum MyEnum1;

Public Enum MyEnum2
	MyValue1 = 0, MyValue2 = 8, MyValue3 = 16
End Enum MyEnum2;
```

## 10. Пространства имён и `Imports`

`Namespace <id> ... End Namespace` — на верхнем уровне или вложенно; всегда `Public`. Имена
уникальны в объемлющем пространстве. Пространства имён **расширяемы** (несколько определений с
одним именем дополняют друг друга). `Global Scope` — глобальное для сборки.

`Imports` импортирует `Public`-элементы пространства имён из ссылочных модулей (без вложенных
пространств имён); локальные структуры имеют приоритет над импортированными. Блок `Imports` должен
идти первым.

```fore
Namespace A
	Class MyClass: Object
		Public Sub Run;
		Begin
			B.Proc1;   // квалифицированно
			Proc4;     // локально
		End Sub Run;
	End Class MyClass;
	Namespace B
		Sub Proc1;
		Begin
		End Sub Proc1;
	End Namespace B;
End Namespace A;
```

## 11. Формальные параметры

- **По значению** — фактический параметр-выражение; **по ссылке** — перед описанием `Var`,
  фактический параметр обязан быть переменной/полем.
- Необязательные параметры (со значением по умолчанию) идут **в конце** списка.
- **`Paramarray`** — массив параметров (только последний, всегда необязательный, одномерный;
  все предшествующие — обязательные).
- Вызов: **позиционно** (без пропусков) или **именованно** (`<имя> := <значение>`); позиционные
  не могут идти после именованных.

```fore
Sub MyProc(a: Integer; Var b: String; c: String = "a");
Begin
	b := c;
End Sub MyProc;

Sub MyProc1(a: Integer; Var b: String; Paramarray c: Array Of Double);
Begin
End Sub MyProc1;
```

## 12. Процедуры и функции

```fore
Sub <Имя>[(<параметры>)];
Begin
End Sub <Имя>;

Function <Имя>[(<параметры>)]: <Тип>;
Begin
	Return <значение>
End Function <Имя>;
```

Процедура — для действий; функция **обязана** вернуть значение (`Return`). `Return` без параметра —
выход из процедуры. Локальные объекты и параметры перекрывают внешние. Идентификатор функции внутри
её тела = рекурсивный вызов. Предварительных описаний нет.

## 13. Область видимости (модификаторы доступа)

Задаёт доступность элемента. Совмещённые модификаторы означают доступ из любого модуля сборки
**и** из класса-потомка в другой сборке. Применяются к константам, переменным, процедурам/функциям,
свойствам, событиям, классам, интерфейсам.

- **`Public`** — общедоступный;
- **`Private`** — только внутри класса;
- **`Protected`** — внутри класса и его потомков;
- **`Friend`** — в любом модуле текущей сборки.

## 14. Массивы

Массив — набор однотипных объектов. Тип элемента — любой системный; по умолчанию `Variant`.
Различают **статические** и **динамические** массивы.

```fore
Var
	a: Array[Min..Max] Of Double;   // статический, с явным типом
	b: Array[Min..Max, Min..Max];   // двумерный (тип по умолчанию Variant)
	c: Array[5, 5];                 // 5x5, индексация 0..4
	d: Array Of Integer;            // динамический
Begin
	d := New Integer[10, 10];       // создание динамического массива (в т.ч. многомерного)
	a[0] := 100;                    // доступ по индексу: arr[i(, j)]
```

- Статический массив можно инициализировать значениями разных типов: `array[7] Of Variant = [1, True, 't', 9223372036854775807, "про", 1.123m, 1.123E5];`
- Массив в `Variant`: создание `New Double[3]`, доступ через `v As Array Of Double`.
- При **повторном создании** динамического массива прежние данные теряются; при присваивании
  массивов — **копирование** (размеры и типы должны совпадать).

## 15. Операции

**Арифметические** (по приоритету): `*`, `/`, `Mod`, `Div`, `+`, `-`. Если в выражении есть `/` —
результат вещественный; `Mod`/`Div` для целых дают целое.

**Логические** (по приоритету): `And`, `Or`, `Xor` (только для логических операндов). Для `And`/`Or`
второй операнд не вычисляется, если результат уже определён.

**Отношения:** `=`, `<>`, `>`, `<`, `>=`, `<=`. Применяются к числам, `Char`, строкам; `=`/`<>` —
и к логическим. Результат — логический.

**Унарные:** унарный `+`, унарный `-`, `Not`.

**Преобразование типов:** `As` (приведение объекта к классу/интерфейсу/типу; при неудаче —
исключение) и `Is` (проверка возможности приведения; результат — логическое значение).

## 16. Операторы

### Условные

**`?:`** — тернарный: `Условие ? ЗначениеЕслиTrue : ЗначениеЕслиFalse`.

```fore
Debug.WriteLine(i > j ? "i>j" : "i<j");
```

**`If ... Then ... Elseif ... Else ... End If`**:

```fore
If (a > b) And (b > c) Then
	c := a - b;
Elseif (a < b) And (b < c) Then
	c := b - a;
Else
	c := (a + b) / 2
End If;
```

**`Select Case`** — по значению, списку, диапазону (`Case 1,2,3`, `Case 1 To 3`, `Else`):

```fore
Select Case a
	Case 1, 2, 3:  c := c + 10;
	Case 4 To 6:   c := c + 1;
	Else c := 0;
End Select;
```

### Циклы

**`For`** — `For <счётчик> := <нач> To <кон> [Step <шаг>] Do ... End For` (счётчик — целого типа;
шаг по умолчанию 1; отрицательный шаг уменьшает счётчик; шаг 0 → исключение):

```fore
For a := 1 To 10 Step 2 Do
	b := b + a
End For;
```

**`For Each`** — `For Each <переменная> In <коллекция> Do ... End For` (по элементам массива/коллекции;
оптимизирован для `IDimElementArray`):

```fore
For Each s In Arr1.Items Do
	Debug.WriteLine(s);
End For;
```

**`Repeat ... Until <условие>`** — условие проверяется **после** тела:

```fore
Repeat
	b := b + b * 5 - 25 * c - 3;
	a := a + 1;
Until a = 10
```

**`While <условие> Do ... End While`** — условие проверяется **до** тела:

```fore
While a < 10 Do
	b := b + 1;
	a := a + 1;
End While;
```

### Оператор `With`

Задаёт синоним квалифицированного идентификатора внутри блока:

```fore
With lbl: Label1.Font Do
	lbl.Bold := True;
	lbl.Color := GxColor.FromName("Red");
	lbl.Size := 15;
End With;
```

### Операторы перехода

- **`Break`** — прерывает текущий цикл (вне цикла — ничего не делает);
- **`Continue`** — переходит к следующей итерации цикла;
- **`Return`** — выход из подпрограммы; для функции — с выражением результата.

### Оператор `Dispose`

Гарантирует **немедленное** освобождение объекта, не дожидаясь сборщика мусора (актуально для
файлов/потоков). Мотивация: после `Fs := Null` файл может оставаться занятым до срабатывания GC.

```fore
FileName := Path.GetTempFileName;
Fs := New FileStream.Create(FileName, FileOpenMode.Create, FileShare.Exclusive);
Try
	// работа с файлом
Finally
	Fs := Null;            // без Dispose файл может оставаться занятым
	File.Delete(FileName);
End Try;
```

> Соответствующая тема в руководстве — «Оператор Dispose» (файл `fore_dispose.htm`).

## 17. Импорт внешних модулей

**`Comimport`** — импорт классов/интерфейсов из dll/tlb (COM). После `From` — GUID библиотеки или
путь к tlb. Импортируются интерфейсы (`Interface`) и классы (`Class`); для импортированных классов
объекты создаются оператором `New`.

```fore
Comimport From "d:\\Work\\TestCom\\TestCom\\bin\\Debug\\TestCom.tlb"
	Interface ITest;
	Class Test: Object, ITest
	End Class Test;
End Comimport;

Sub Main;
Var
	a: Test;
	i: Integer;
Begin
	a := New Test.Create;
	i := a.TestSumm(1, 9);
End Sub Main;
```

Альтернативно — по GUID: `Comimport From "{ef6d37f5-ee50-4029-929f-e31e92e9164d}"`.

**`Pyimport`** — импорт функций/классов из Python-модулей (репозиторных и системных). Два варианта:
`Pyimport <модуль>;` (обращение `<модуль>.<функция>`) и `Pyimport <f1>, <f2> From <модуль>;`.
У импортированных классов доступны только **статические** поля/методы; все параметры и результаты —
типа `Variant`.

```fore
Pyimport math, time;
Pyimport randint From random;
Pyimport pytest;              // Python-модуль из репозитория (Id = PYTEST)

v := math.sqrt(10);
v := pytest.summxy(3, 7);
v := pytest.testclass.getpi(Null);
```

## 18. Обработка исключительных ситуаций

Оператор **`Try ... Except ... Finally ... End Try`**:

- **`Try`** — блок, где возможна исключительная ситуация;
- **`Except`** — блок обработки; содержит подблоки **`On <переменная>: <Класс> Do ...`**, где
  указывается **класс** исключения (не интерфейс); переменная даёт доступ к сведениям (`Message`,
  `Line`, `Source`, `MessageID`);
- **`Finally`** — выполняется всегда при выходе из блока.

```fore
Try
	a[2] := 1;
Except On e: IndexOutOfRangeException Do
	Debug.WriteLine(e.Line);
	Debug.WriteLine(e.Message);
End Try;

Try
	f := File.Open("c:\\fileabcxyz666.txt", FileOpenMode.Read, FileShare.Exclusive);
Except On e: FileNotFoundException Do
	Debug.WriteLine(e.Message);
Finally
	Debug.WriteLine("Данный блок выполняется всегда");
End Try;
```

**Системные классы исключений:** `Exception` (базовый), `AccessViolationException`,
`ArgumentException`, `ArgumentNullException`, `ArgumentOutOfRangeException`, `ArithmeticException`,
`DivideByZeroException`, `DirectoryNotFoundException`, `FileNotFoundException`, `IOException`,
`EndOfStreamException`, `IndexOutOfRangeException`, `NotFiniteNumberException` и др. Если класс
неизвестен — указывается базовый `Exception`.

## 19. Сообщения компилятора Fore

Полный перечень — в руководстве (файлы `msgerror_*.htm`, коды 1005…1152). Ниже — сводный список
формулировок (для быстрой идентификации).

**Идентификаторы, типы, члены класса**
- Переменная/Константа `<наименование>` не используется; Свойство/метод `<имяЧлена>` является устаревшим
- Неизвестный идентификатор `<идентификатор>`; Повторное определение идентификатора; Повторное определение константы
- Идентификатор `<...>` встречается в сборках `<...>` и `<...>`; Идентификатор превышает максимальную допустимую длину 255 символов
- `<имяТипа>` не является классом или перечислением, либо в описании используется директива private
- По левую сторону от `.` должен быть объект, класс, перечисление или модуль
- Объект класса `<1>` не может быть приведён к классу `<2>`; Типы `<1>` и `<2>` не совместимы
- Операция `<...>` недопустима для операнда(ов) типа `<...>`
- Для данного объекта класса `<...>` отсутствует свойство «по умолчанию»; В классе может быть только одно свойство «по умолчанию»
- Индексированному свойству нельзя ставить в соответствие поля; Метод, реализующий индексированное свойство, не может содержать параметры по ссылке
- Свойство `<...>` доступно только для чтения; Недопустимое использование свойства, доступного только для записи
- Недопустимая директива default для неиндексированного (статического) свойства
- Директива `<...>` недопустима для `<члена>`
- Недопустимое сочетание статических и нестатических членов класса; Нельзя вызвать нестатический метод из статического; Из статического метода нельзя обратиться к нестатическому полю

**Наследование, интерфейсы, делегаты**
- Класс не может наследоваться от интерфейса; Интерфейс может наследоваться только от интерфейса
- Интерфейс `<...>` не определен; Метод `<...>` интерфейса `<...>` не реализован
- Нельзя наследовать от класса `<...>`; Используется циклическое наследование класса `<...>` от самого себя
- Переопределение метода с директивой Final недопустимо; Недопустимое переопределение метода в интерфейсе
- Метод `<...>` в базовом классе не найден; Недопустимое использование inherited вне тела нестатического метода
- Определение процедуры `<...>` в классе `<...>` отличается от предыдущего определения в базовом классе
- Определение процедуры в классе отличается от определения события в классе
- Пользовательский интерфейс не может наследоваться от системного интерфейса
- Ожидается имя делегата; Недопустимое использование делегата; Делегат ссылается на метод, не принадлежащий классу

**Параметры и вызовы**
- Метод `<...>` должен содержать `<N>` параметр(а,ов); Определены не все обязательные параметры (индексы при чтении/записи свойства)
- Параметр `<...>` уже встречался в списке; В методе `<...>` отсутствует параметр с именем `<...>`
- Параметр, передаваемый по ссылке, не может иметь значения по умолчанию; Для параметра по ссылке ожидается поле или переменная типа `<...>`
- Метод `<...>` не может содержать параметры, передаваемые по ссылке
- Тип параметра `<...>` метода `<...>` не совместим с типом индекса/свойства `<...>`
- Типом параметра ParamArray должен быть массив без указания размера; Параметр ParamArray нельзя использовать как именованный
- Конструктор с именем `<...>` не найден

**Операторы, операторы языка, модули**
- Недопустимое использование оператора `<...>` вне цикла / в блоке finally
- Недопустимое использование счетчика цикла `<...>`; В качестве счётчика цикла ожидается локальная переменная
- Оператор new недопустим для интерфейсов / простых типов; Оператор new[] допустим только для простых типов
- Тип `<...>` не поддерживается оператором For Each
- Блок Imports должен предшествовать всем другим блокам; `<имяТипа>` не является пространством имён
- Операторы для пользовательских классов не поддерживаются
- В теле функции не найден оператор return
- Левая часть оператора `:=` не допускает присваивания; Выражение не может быть присвоено списку переменных

**Синтаксис, литералы, компиляция**
- Ожидается выражение / оператор / константное выражение / выражение простого (логического, целого) типа
- Ожидается идентификатор / имя класса / ключевое слово `<...>` / символ '`<...>`' / строка с GUID библиотеки
- Ожидается get или set; После get ожидается идентификатор функции; После set ожидается идентификатор процедуры
- Ожидается определение блока модуля / метода или свойства интерфейса / метода, поля или свойства класса
- После `<спецификатор доступа>` ожидается идентификатор поля или метода
- Многострочный комментарий не завершён (ожидается `}`); Неоконченная строка (ожидается `"`)

- Перечисление должно содержать определение хотя бы одной константы
- Несовместимые размерности массивов; Избыточное количество индексов
- Компиляция сборки `<...>` завершилась с ошибкой; Сборка `<...>` подключается циклически
- В сборке `<...>` используется модуль с именем системного модуля `<...>`; Недоступно для использования в веб
- Не удалось загрузить библиотеку `<...>`; Слишком много методов в импортируемом интерфейсе
