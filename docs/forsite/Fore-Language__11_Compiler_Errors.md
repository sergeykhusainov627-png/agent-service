## Ожидается выражение

Ожидается выражение
Описание
Оператор в качестве своего правого операнда требует выражение, однако
выражение отсутствует.
Способ устранения
Необходимо добавить допустимое выражение в качестве правого операнда.
Пример
Sub  Main;
Var
i: Integer;
Begin
i :=;
End   Sub  Main;
При компиляции указанного кода на строке «i :=;» будет сгенерирована
ошибка «Ожидается выражение». Для разрешения ошибки необходимо дописать
какое-либо выражение, возвращающее целочисленное значение.

## Константное выражение должно быть не меньше &lt;значение&gt;

Константное выражение должно быть не меньше <значение>
Описание
При указании диапазона допустимых значений левая граница имеет значение
больше правой.
Способ устранения
Проверьте значения используемых констант, установите значение не меньше
указанного значения.
Пример
Sub  UserProc;
Const
Min =  0 ;
Max = - 5 ;
Var
a: Array[Min..Max];
Begin
End   Sub  UserProc;
При компиляции указанного кода в строке объявления массива на константе
«Max» будет сгенерирована ошибка «Константное выражение должно быть не
меньше 0». Для разрешения ошибки необходимо установить соответствующее
значение для константы «Max».

Выражение не может быть присвоено списку переменных
Описание

Пример

End   Sub  UserProc;

не может быть присвоено списку переменных». Для разрешения ошибки необходимо
каждую переменную объявить отдельно и указать требуемое значение по умолчанию.

## Объект класса &lt;имяКласса1&gt; не может быть приведен к классу &lt;имяКласса2&gt;

Объект класса <имяКласса1> не может быть приведен к классу <имяКласса2>
Описание
В коде предпринята попытка преобразования между двумя объектами, несовместимыми
по классу. Класс объекта, преобразование которого осуществляется к другому
классу, не является его наследником.
Способ устранения
Необходимо проверить классы преобразуемых объектов. Возможно некорректно
указано наследование классов.
Пример
Class  A: Object
End   Class  A;
Class  B: Object
End   Class  B;
Sub  UserProc;
Var
Obj1: A;
Obj2: B;
Begin
Obj1 := Obj2  As  A;
End   Sub  UserProc;
При компиляции указанного кода на строке «Obj1 := Obj2 As A;»
будет сгенерирована ошибка «Объект класса B не может быть приведен к классу
A». Ошибка возникает из-за того, что класс B не является наследником класса
A и между ними невозможно явное преобразование.

## По левую сторону от . должен быть объект, класс, перечисление или модуль

По левую сторону от . должен быть объект, класс, перечисление или модуль
Описание
В блоке кода для константы осуществляется вызов методов, доступных для
соответствующего типа данных.
Способ устранения
В среде разработки, если после идентификатора константы установить «.»
, то в IntelliSense будет сформирован список методов, доступных для соответствующего
типа данных. Использование данных методов для констант запрещено. Необходимо
удалить вызов любых методов для константы либо переместить описание константы
в блок переменных.
Пример
Sub  UserProc;
Const
d =  1 ;
Begin
d.Parse( "1" );
End   Sub  UserProc;
При компиляции указанного кода на строке «d.Parse("1");» будет
сгенерирована ошибка «По левую сторону от . должен быть объект, класс,
перечисление или модуль». Для разрешения ошибки необходимо удалить вызов
метода «Parse» для константы «d».

## Метод, реализующий индексированное свойство не может содержать параметры, передаваемые по ссылке

Метод, реализующий индексированное свойство не может содержать параметры,
передаваемые по ссылке
Описание
При использовании  старого
способа объявления свойств  в сигнатуре процедуры/функции, используемой
для обработки доступа к свойству, первые переменные, отвечающая за индексы
свойства, передаются по ссылке (объявлены с ключевым словом Var). Передача
параметров по ссылке в таких случаях запрещена спецификацией языка  Fore .
Способ устранения
Удалите ключевое слово  Var ,
установленное перед первыми параметрами в заголовке процедуры/функции,
используемой свойством.
Пример
Class  MyClass: Object
Private  PropValue: Array  Of  String;
Public   Constructor  Create(Length: Integer);
Begin
PropValue :=  New  String[Length];
End   Constructor  Create;
Sub  Set_Item( Var  i: Integer; s: String);
Begin
PropValue[i] := s;
End   Sub  Set_Item;
Function  Get_Item( Var  i: Integer): String;
Begin
Return  PropValue[i];
End   Function  Get_Item;
Public   Property  Item(i: Integer): String  Get  Get_Item  Set  Set_Item;
End   Class  MyClass;
При компиляции указанного кода будет сгенерирована ошибка «Метод, реализующий
индексированное свойство не может содержать параметры, передаваемые по
ссылке». Для разрешения ошибки необходимо удалить ключевое слово «Var»,
указанное перед параметром «i» в области объявления переменных в процедуре
Set_Item и функции Get_Item.

## Параметр &lt;имяПараметра&gt; уже встречался в списке

Параметр <имяПараметра> уже встречался в списке
Описание
При вызове процедуры/функции с использованием именованных параметров
для одного или более параметров значение указано больше одного раза.
Способ устранения
Удалить дублирующиеся значения параметров. Для каждого параметра должно
указываться только одно значение. Способы вызова с различными вариантами
указания параметров представлены в разделе Операторы.
Пример
Sub  UserProc(a: Integer; b: String);
Begin
End   Sub  UserProc;
Sub  Main;
Begin
UserProc(a :=  3 , b :=  "a" , b :=  "b" );
End   Sub  Main;
При компиляции указанного кода на строке «UserProc(a := 3, b := "a", b := "b");»
будет сгенерирована ошибка «Параметр b уже встречался в списке». Ошибка
возникает из-за того, что значение параметра «b» указано два раза.

явным образом указать идентификатор свойства Item -  i := Obj.Item(1);

Индексированному свойству нельзя ставить в соответствие поля
Описание
При использовании  старого
синтаксиса  описания свойства с параметрами после спецификатора доступа
указано поле класса.
Способ устранения
Поля класса могут быть использованы только при описании свойств без
параметров. Если свойство имеет параметры, то в качестве обработчиков
должны использоваться методы.
После спецификатора доступа  Get
должен быть указан метод, имеющий такое же количество параметров, как

После спецификатора доступа  Set

свойству нельзя ставить в соответствие поля». Для разрешения ошибки необходимо
выполнить одно из следующих действий:
В описании свойства убрать параметр «i».
После спецификатором доступа  Get
и  Set  указать идентификаторы
функции и процедуры соответственно.

Интерфейс может наследоваться только от интерфейса
Описание
Нарушено правило наследования интерфейсов, определенное спецификацией

иерархию наследования, унаследовав интерфейс «IMyInterface3» от интерфейса

описание класса «UserClass», указав список реализуемых интерфейсов.

## Метод &lt;имяМетода&gt; должен содержать &lt;количествоПараметров&gt; параметр(а,ов)

Метод <имяМетода> должен содержать <количествоПараметров>
параметр(а,ов)
Описание
При использовании старого синтаксиса описания свойств в указанном методе
количество параметров не соответствует количеству индексов описываемого
свойства.
Способ устранения
Проверьте количество параметров, указанных в сигнатуре используемых
процедур/функций:
В функции, указываемой после спецификатора  Get ,
количество параметров должны совпадать с количеством индексов описываемого
свойства.
В процедуре, указываемой после спецификатора  Set ,
количество параметров должны быть на один больше чем количеством индексов
описываемого свойства. Тип последнего дополнительного параметра в
методе должен совпадать с типом свойства.
Допишите недостающие параметры в используемые методы, либо удалите лишние
параметры из описания свойства.
Пример
Class  MyClass: Object
i: Integer;
Function  Func: Integer;
Begin
Return  i
End   Function  Func;
Property  Item(a: Integer; b: String): Integer  Get  Func;
End   Class  MyClass;
При компиляции указанного кода будет сгенерирована ошибка «Метод Func
должен содержать 2 параметр(а,ов)». Для разрешения ошибки необходимо выполнить
одно из следующих действий:
в заголовке функции «Func» добавить два параметра;
в заголовке свойства «Item» удалить два параметра.

## Нельзя вызвать нестатический метод из статического

Нельзя вызвать нестатический метод из статического
Описание
Статические члены могут быть вызваны без создания экземпляра класса.
Нестатические члены могут быть вызваны только для экземпляра класса. При
обращении к статическому члену экземпляр данного класса еще не инициализирован,
что приводит к невозможности использовать его нестатические методы.

## Определены не все обязательные индексы при чтении свойства &lt;имяСвойства&gt;

Определены не все обязательные индексы при чтении свойства <имяСвойства>
Описание
При чтении значения свойства были пропущены значения одного или более
обязательного индекса.
Способ устранения
Установите значения всех обязательных индексов свойства.
Пример
Class  TestClass: Object
s: Array  Of  String;
Public   Constructor  Create(Length: Integer);
Begin
s :=  New  String[Length]
End   Constructor  Create;
Public   Property  Item(i: Integer): String
Get
Begin
Return  s[i];
End   Get
Set
Begin
s[i] := Value;
End   Set
End   Property  Item;
End   Class  TestClass;
Sub  UserProc;
Var
Obj: TestClass;
s: String;
Begin
Obj :=  New  TestClass.Create( 4 );
s := Obj.Item;
End   Sub  UserProc;
При компиляции указанного кода на строке «s := Obj.Item;»
будет сгенерирована ошибка «Определены не все обязательные индексы при
чтении свойства Item». Для разрешения ошибки необходимо указать значение
обязательного индекса «i».

## Метод &lt;имяМетода&gt; не может содержать параметры, передаваемые по ссылке

Метод <имяМетода> не может содержать параметры, передаваемые
по ссылке
Описание
При использовании  старого
способа объявления свойств  в качестве обработчика Set-части указана
процедура, содержащая в своей сигнатуре параметры, передаваемые по ссылке
(с ключевым словом Var). В качестве обработчиков допустимо использовать
только процедуры с параметрами, передаваемыми по значению.
Способ устранения
Удалите ключевое слово  Var ,
установленное перед параметрами в заголовке процедуры, используемой свойством.
Пример
Class  MyClass: Object
Private  PropValue: Array  Of  String;
Public   Constructor  Create(Length: Integer);
Begin
PropValue :=  New  String[Length];
End   Constructor  Create;
Sub  Set_Item(i: Integer;  Var  s: String);
Begin
PropValue[i] := s;
End   Sub  Set_Item;
Function  Get_Item(i: Integer): String;
Begin
Return  PropValue[i];
End   Function  Get_Item;
Public   Property  Item(i: Integer): String  Get  Get_Item  Set  Set_Item;
End   Class  MyClass;
При компиляции указанного кода будет сгенерирована ошибка «Метод 'Set_Item'
не может содержать параметры, передаваемые по ссылке». Для разрешения
ошибки необходимо удалить ключевое слово «Var», указанное перед параметром
«s» в области объявления переменных процедуры Set_Item.

## Переменная/Константа &lt;наименование&gt; не используется

Переменная/Константа <наименование> не используется
Описание
В блоке объявления локальных переменных Var пользовательской процедуры/функции присутствуют неиспользуемые переменные/константы. Возможно, допущена ошибка в написании локальных переменных.
Способ устранения
Данное сообщение является предупреждением и может быть проигнорировано. Для устранения необходимо проверить наличие орфографических ошибок в наименованиях локальных переменных. Если орфографические ошибки отсутствуют, то необходимо либо удалить неиспользуемые переменные/константы, либо поместить их в область комментариев.

## Свойство/метод &lt;имяЧлена&gt; является устаревшим

Свойство/метод <имяЧлена> является устаревшим
Описание
В блоке кода встретилось использование каких-либо системных свойств/методов,
помеченных разработчиками как устаревшие. Свойства/методы, помеченные
как устаревшие, более не поддерживаются в платформе. В более поздних версиях
они будут недоступны для использования. Необходимо избегать использования
таких свойств/методов для предотвращения возникновения ошибок при переходе
на более новые версии продукта «Форсайт. Аналитическая платформа».
Возможные различные контексты данного предупреждения:
Свойство/метод <наименование> является устаревшим
Свойство/метод <наименование> является устаревшим, используйте
<наименование>
Способ устранения
В зависимости от контекста предупреждения необходимо полностью отказаться
от использования свойства/метода и реализовать пользовательскую задачу
с использованием других ресурсов платформы, либо использовать указанное
в предупреждении свойство/метод.

## Компиляция сборки 'идентификаторСборки' завершилась с ошибкой

Компиляция сборки 'идентификаторСборки' завершилась с ошибкой
Описание
Данная ошибка компиляции генерируется автоматически при возникновении каких-либо других ошибок компиляции.
Способ устранения
Данная ошибка компиляции будет разрешена при разрешении всех остальных ошибок, возникших при компиляции текущей сборки.
