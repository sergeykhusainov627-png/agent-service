## PamAssemblyMethod

PamAssemblyMethod
Описание
Перечисление  PamAssemblyMethod
используется для определения способа подключения объекта среды разработки
к регламентному отчёту, входящему в состав формы ввода.
Используется следующим методом:
IPrxAssemblies.AddEx.
Возможные значения
Значение |
Краткое описание |
0 |
ReportAndTabsheet .
По умолчанию. Объект среды разработки подключён к регламентному
отчёту и таблице. |
1 |
OnlyReport . Объект
среды разработки подключён только к регламентному отчёту. |
Комментарии
Если при построении формы ввода не планируется  обработка
событий таблицы , то используйте значение  OnlyReport .
За счёт данного способа подключения объекта среды разработки к регламентному
отчёту сокращается время открытия формы ввода.

## PrxMapAdapter

PrxMapAdapter
Описание
Перечисление  PrxMapAdapter  содержит типы адаптера для карты.
Используется следующими свойствами и методами:
IPrxDataAdapterManager.CreateSliceMapDataAdapter ;
IPrxDataAdapterManager.CreateRangeMapDataAdapter ;
IPrxMapDataAdapter.AdapterType ;
IPrxSlice.CreateMapDataAdapter .
Возможные значения
Значение |
Краткое описание |
0 |
None  .  Тип адаптера не определен. |
1 |
Static  .  Статический. |
2 |
Dynamic  .  Динамический. |
3 |
ShapeText  .  А даптер для областей слоя.  |
4 |
TerritoryInfo  .  Адаптер для расшифровки территорий. |
Комментарии
Статический адаптер берет данные по одной точке. Пример использования перечисления  Static  - картографические показатели  IMapAreaVisual . В качестве данных берется координата на карте, соответствующая показателю.
Динамический адаптер берет данные по нескольким точкам. Пример использования перечисления  Dynamic  - круговые ( IMapPieVisual ) и столбиковые ( IMapBarVisual ) показатели. В качестве данных для конкретного региона берутся значение показателя и максимальное число отображаемых секторов показателя ( PiesCount ) для круговых показателей или максимальное количество столбиков показателя ( BarsCount ) для столбиковых показателей соответственно.
